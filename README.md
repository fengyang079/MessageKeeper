# MessageKeeper

Android 本地消息归档与在线状态协同工具。通过系统通知监听捕获聊天应用的通知，按会话归档到本地 SQLite；并提供会话检索、消息统计、特别提醒、自动备份、整机迁移以及 **State Online 实时状态与事件脉络联动** 等能力。

- 版本：1.4.0（versionCode 21）
- 最低系统：Android 8.0（API 26）
- 编译/目标 SDK：API 36
- 语言/UI：Kotlin + Jetpack Compose（Material 3）
- 开源协议：MIT

## 简介

MessageKeeper 基于 Android 的 `NotificationListenerService`，在系统通知层拦截微信、QQ、抖音、多闪、QQ 音乐等应用的通知，解析出会话、发送者与正文后写入本地数据库。由于数据在通知到达时就已经落库，即使对方随后撤回消息，已记录的内容仍然保留。

聊天记录模块无第三方云端：全部聊天数据保存在设备本地的 Room(SQLite) 数据库中，不接入任何第三方统计或广告 SDK。网络能力仅用于：
1. 用户手动发起的局域网手机间数据迁移；
2. 用户主动配置的自建 **State Online（在线状态与事件脉络）** 服务端协同。

## 功能特性

### 通知拦截与防撤回
- 通过 `NotificationListenerService` 实时捕获目标应用的通知，内置支持微信、QQ、抖音、快手、多闪、QQ 音乐；可在「设置 → 监听应用管理」中启停平台并自定义显示名称。
- 解析层负责：清洗标题前缀、兼容全角/半角标点、拆分群聊的「发送者: 内容」格式、合并带 `(X条新消息)` 后缀的重复会话、识别软件通知（不计入聊天统计）。
- 以「通知 ID + 内容 + 时间戳」判重，通知监听服务重连后重新扫描通知栏不会产生重复记录。
- 撤回通知会定位到该会话中最近的一条未撤回消息并标记为「已撤回」，原始内容保留。

### 会话与消息管理
- 会话列表：置顶、排除统计、会话类型（自动 / 群聊 / 私信）、按联系人/内容全局搜索。
- 消息时间轴：按天分隔、已撤回消息高亮展示；置顶状态额外持久化在本地偏好中，升级、会话合并或数据还原后仍可恢复。
- 删除消息/会话需二次确认；删除的内容会进入本地回收站（`deleted_messages` 表），可在「设置 → 数据管理与备份 → 历史删除恢复」中查看，支持单条、按会话或全部恢复，也可彻底清空。

### 在线状态与事件脉络（State Online 联动）
- **实时状态大屏**：同步展示与管理个人实时在线状态、长方形分类标签（8 色低饱和标准色板）、2x2 核心事件指标（进行中、L4+ 高紧急、已归档、近 7 天跟进）、快捷预设状态一键切换及带时间戳的历史状态记录。
- **事件脉络跟踪**：支持多级紧急度（L1 ~ L5）与多级可见性权限（L0 ~ L4）的事件创建、自定义类目筛选、归档/置顶管理；支持连续时间线跟进（跟进 / 问题原因 / 解决方法 / 反馈 / 反思 / 里程碑 / 待办）。
- **多图与附件上传**：移动端追加跟进时支持从系统相册/文件选择器批量上传图片与附件，内置远程缩略图解码与全屏大图预览；支持一键导出事件复盘 Markdown。
- **账号密码登录与自动绑定 Key**：支持在 App 内直接通过用户名密码登录或注册新账户，完成后自动获取并填入专属 `API Key`（输入框默认掩码防窥，支持一键显示/隐藏）。
- **管理员回收站（最近删除）与终端审计**：管理员（L4）专属「最近删除」回收站（保留最近 30 天删除的事件、历史状态与跟进记录，支持一键恢复或彻底清理）以及「终端审计」面板（0-4 级滑块实时在线提权/降权、查看登录 IP 与设备指纹历史）。
- **流畅加载体验**：内置顶置变形流体进度条（Morphing Progress Bar）与事件列表呼吸骨架屏，切换类目、上传附件与请求数据时即时反馈，彻底消除等待假死感。

### 情报统计
- 支持按「全部联系人」或指定联系人群聊查看统计。
- 已保存消息总数（默认排除软件通知与 QQ 音乐）。
- 消息发送趋势折线图，时间范围可切换 5 小时 / 12 小时 / 1 天 / 7 天 / 1 月 / 6 月 / 1 年。
- 最近 7 天每日消息量柱状图、消息最多的会话 Top 5、历史消息的 24 小时时段分布。

### 特别提醒
- 可按联系人 / 群设置提醒规则，支持启用停用、试听与测试。
- 命中规则时通过高优先级通知、持续震动、`WAKE_LOCK` 亮屏等方式提醒。
- 内置提示音：默认、静音、叮咚、甘露、警报。

### 睡眠模式
- 手动开启「我睡觉啦」，或设置定时睡眠计划（默认 22:00 - 07:00，到点自动开关并发送系统通知）。
- 睡眠模式下，特别关心联系人的消息会播放闹钟铃声持续响铃，直到手动停止。

### 备份与恢复
- 每天自动生成一份全量备份（GZIP 压缩的 JSON），也可随时手动「立即备份」。
- 设置 →「数据管理与备份 → 每日自动备份」页可浏览备份内容（会话列表 → 消息只读预览），并对任意备份执行：
  - **回退**：先用当前数据生成一份「回退前」备份，再整体替换为所选备份；
  - **合并**：只补齐本地没有的消息，不删除、不覆盖本地已有数据（自动去重）；
  - **删除**：删除该备份存档。
- 备份写入时先写临时文件再改名，避免产生半截存档。

### 备份自动清理
- 用于清理**旧备份文件**（不影响数据库内的聊天记录），保留天数可选 关闭 / 7 / 30 / 90 天，默认 30 天。
- 每日后台最多执行一次；此外无论设置如何，备份数量上限为 20 份，超出后从最旧的开始清理。

### 数据导出
- 全量 JSON：可导出/导入，用于备份与恢复。
- TXT / HTML：把会话记录渲染为静态文件，HTML 可直接用浏览器打开归档。

### 手机间迁移（局域网）
- 接收端开启服务后显示本机 IP 与 6 位配对码（端口 38472），发送端输入 IP + 配对码即可推送。
- 迁移为**合并**语义：只补充对端没有的消息，不删除本地数据；同一时刻的相同消息只保留一条，两台设备同时在线导致的时间戳抖动（±2 秒）会做一对一配对去重。

### 后台保活
- 前台服务 + 可选的无障碍服务保活 + 60 秒精确闹钟心跳自检（检测通知监听服务存活并尝试重建）。
- 开机自启；备份与清理任务只在主进程执行，避免保活框架的多进程并发写库。

### 界面与交互
- 深色终端风格界面；长按消息时菜单跟随手指弹出。
- 删除消息/会话带碎裂粒子动画；关键删除操作均配备二次确认弹窗。
- 会话列表不提供滑动删除，删除统一走长按 / 更多菜单，避免误触。
- 全局 toast 反馈（复制、置顶、统计开关、备份、回退、状态同步、主题切换等操作均有提示）。

## 编译与运行

```bash
# 克隆仓库
git clone https://github.com/fengyang079/MessageKeeper.git
cd MessageKeeper

# 编译 Debug APK（输出 app/build/outputs/apk/debug/app-debug.apk）
./gradlew :app:assembleDebug

# 编译 Release APK（输出 app/build/outputs/apk/release/app-release.apk）
./gradlew :app:assembleRelease

# 直接安装到已连接设备
./gradlew :app:installDebug
```

说明：

- 依赖仓库使用 Google / Maven Central；`settings.gradle.kts` 中为国内网络预置了阿里云镜像。
- `local.properties` 中的 SDK 路径由 Android Studio 自动生成，未纳入版本控制。
- Release 构建开启了 R8 代码混淆与压缩（`isMinifyEnabled = true`），目前默认沿用 debug 签名以便直接安装测试；如需正式分发请配置您自己的签名密钥。

## 首次使用与权限

安装后需要在系统设置中完成以下授权，否则无法正常捕获消息：

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| 通知使用权（`BIND_NOTIFICATION_LISTENER_SERVICE`） | 读取聊天通知，核心功能 | 必需 |
| 通知权限（`POST_NOTIFICATIONS`） | 展示前台服务与特别提醒通知 | 建议 |
| 忽略电池优化（`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`） | 降低后台被系统暂停的概率 | 建议 |
| 后台弹窗 / 全屏通知（`USE_FULL_SCREEN_INTENT`） | 特别提醒强提醒 | 可选 |
| 无障碍服务 | 辅助保活（不读取屏幕内容） | 可选 |
| 精确闹钟（`SCHEDULE_EXACT_ALARM`） | 60 秒心跳自检 | 可选 |
| 网络（`INTERNET` / 网络状态） | 局域网手机互传与自建 State Online 状态同步 | 可选 |
| 存储（`maxSdkVersion 28/32`） | 导出文件到公共目录 | 可选 |

应用内「完成基础设置」页会引导逐项开启；也可在系统设置中手动授权。

## 数据存储与隐私安全

- **本地聊天数据库**：`/data/data/com.messagekeeper/databases/message_keeper.db`（Room 沙盒存储，仅本应用私有可读）。
- **禁止系统云端自动备份**：`AndroidManifest.xml` 中已设置 `android:allowBackup="false"`，防止系统云备份或 `adb backup` 导出私有聊天数据库与凭据。
- **凭据防窥保护**：State Online 服务的登录密码与 `API Key` 输入框均默认启用掩码隐藏（`PasswordVisualTransformation`），防止截屏或肩窥泄露；退出账户时一键清空本地保存的 `API Key`。
- **分级权限门控**：非管理员用户在客户端不展示「最近删除」回收站、「终端审计」面板及管理变更操作，且服务端接口强制校验管理员权限。
- **自动/手动备份**：`Android/data/com.messagekeeper/files/backups/`（`*.json.gz` + 同名 `.meta`）。
- **导出的 TXT/HTML**：`Android/data/com.messagekeeper/files/Download/MessageKeeper/`。
- **无第三方上报**：应用不包含任何第三方统计、崩溃上报或广告 SDK；本地捕获的聊天通知不会上传至任何服务器。
- 卸载应用会清除应用沙盒内的数据库与备份，请提前使用「立即备份」或「导出记录(JSON)」留档。

## 备份文件说明

- 内容格式为 JSON：`version`、`exported_at`、`conversations[]`、`messages[]`；整个 JSON 经 GZIP 压缩保存，并用同名 `.meta` 记录时间、类型、条目数与大小。
- 备份类型：`auto`（每日自动）、`manual`（手动）、`prerestore`（回退前自动生成）。
- 保留策略：默认保留最近 30 天（可在设置中改为 0 / 7 / 30 / 90 天，0 表示不按时间清理），且最多 20 份。
- 回退与合并不会修改特别提醒规则（规则保存在 `special_alerts` 表，不随备份迁移）。

## 常见问题

**收不到任何消息？**
1. 确认系统设置中已为本应用开启「通知使用权」；
2. 确认来源应用在「设置 → 监听应用管理」中处于启用状态；
3. 部分厂商（华为/荣耀/小米/OPPO/vivo）需要额外允许自启动、后台运行、关闭电池优化；
4. 若开启过「睡眠模式」，普通通知不会响铃，但消息仍会记录。

**为什么同一条消息只记录到一次/有时内容不全？**
微信、QQ 对同一会话的连续消息会复用并刷新同一条通知，系统通知本身只保留最新文本，因此归档粒度取决于通知内容，无法还原完整聊天记录。

**迁移后消息会不会重复或覆盖？**
不会覆盖。迁移是合并语义，并按「同一时刻的相同消息」去重；两台设备同时在线时，时间戳抖动在 ±2 秒内的同内容消息会被视为同一条。

**「已保存消息」数量为什么比聊天软件少？**
统计默认排除软件通知与 QQ 音乐；另外通知被系统合并时只记录合并后的文本。

**备份在哪里？换机怎么带走？**
见上文「数据存储与隐私安全」。也可以用「导出记录(JSON)」把文件导出到可访问目录，或使用手机互传直接迁移到新设备。

## 已知限制

- 只能获取通知中携带的文本，无法读取聊天应用的内部数据库。
- 部分厂商系统对后台服务限制严格，长时间不被唤醒时可能漏记通知。
- 跨设备去重的抖动窗口为 ±2 秒：极端情况下，两条内容完全相同且时间间隔小于 2 秒的消息可能被合并为一条。
- 手机互传要求两台设备在同一局域网，且聊天平台与会话命名规则一致。
